# **App Name**: My Movies

## Core Features:

- User Authentication: Secure user account creation, login, and profile management.
- Friend Management: Users can add, delete, and manage their friends within the application.
- Movie Upload and Management: Users can upload movies from their local machines and manage their personal movie library. Admin can manage movies also.also user can watch already inbuilt movies in the system and also can watch alone or with friends or download them
- Synchronized Online Viewing: Users can watch movies together with friends in real-time, with synchronized playback. User can adjust quality using the provided tool that will automatically apply changes on quality for the viewers also.
- Offline Playback: Users can download movies and watch them offline.
- Real-time Chat: Integrated real-time text, voice, and video chat during movie playback.user can mute mic and turn on and off camera only self and also other user also (make sure that this turning off mic and camera works from own user side.  eg. I have turn off my mic the. Nobody will hear me but if I mute single persons mic then that user's audio will be mutes only for me...as like this for video also)
- User and Admin Dashboards: Personalized dashboards for users and administrators to manage content and settings.

## Style Guidelines:

- Primary color: Dark indigo (#4B0082) to create a cinematic and immersive atmosphere.
- Background color: Deep gray (#222222) for a dark, theater-like appearance.
- Accent color: Vibrant purple (#BE29EC) for interactive elements and highlights.
- Headline font: 'Space Grotesk' sans-serif for headlines, providing a modern, techy look.
- Body font: 'Inter' sans-serif for body text, ensuring readability.
- Use clean, outlined icons for navigation and controls.
- Subtle transitions and animations to enhance user experience, such as fading effects for movie posters and smooth scrolling.
